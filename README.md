# Cycling ICU Coach

一个面向普通骑行者的 Agent Skill：用户只需自然交流，Agent 就能完成目标澄清、训练背景采集、成功案例对照、循证计划设计，以及 Intervals.icu 预览与部署。

它特别照顾刚开始系统训练、没有功率计、不参加比赛，或不熟悉电脑和训练术语的人。目标可以是 FTP、绝对功率、功体比、无氧储备、冲刺能力、耐久性，也可以只是更稳定地骑车。

## 它能做什么

- 每轮最多询问 5 个简单问题，允许回答“不知道”“没有”或大概范围。
- 正式计划开始前，主动了解饮食、睡眠、运动补剂、伤病与生活压力。
- 支持无功率计训练，用心率、主观用力程度、谈话测试和可重复测试替代虚假的功率精度。
- 先根据用户原始数据生成基线方案，再与匹配的成功案例比较，明确哪些做法采用、缩放或拒绝。
- 区分科研证据、职业运动员实践、教练经验和社区案例，避免直接照搬职业训练量。
- 可以通过 API、已登录浏览器、数据导出或纯对话四种方式工作。
- 先验证和预览 Intervals.icu 日历内容，获得用户明确授权后才部署。
- 提供跨 Agent 交接格式，让后续 Agent 能沿用已确认信息。

## 安装

把仓库克隆到支持 `SKILL.md` 的 Agent 技能目录。例如 Codex：

```bash
git clone https://github.com/huixiaodou123/cycling-icu-coach.git ~/.codex/skills/cycling-icu-coach
```

也可以下载 ZIP，将整个文件夹复制到对应的 skills 目录。重新打开 Agent 后，用自然语言开始即可。

## 使用示例

```text
帮我把 FTP 从 220W 提升到 250W，但我每周只能骑 4 次。
```

```text
我没有比赛，也没有功率计，想提升爬坡和冲刺能力，请一步步问我。
```

```text
读取我的 Intervals.icu 数据，先比较原始数据方案和成功案例方案，再给我预览，不要直接写入日历。
```

如果 Agent 支持隐式技能调用，普通对话也能触发。用户不需要运行命令、编辑 JSON、查找 athlete ID 或理解 API。

## Intervals.icu 工作方式

技能按以下顺序自动选择可用方式：

1. 已授权的 Intervals.icu API 或连接器；
2. 已登录的浏览器；
3. 用户提供的数据导出；
4. 纯对话与估算数据。

缺少功率计、API 或导出文件不会中断流程。信息不足时，技能会先生成讨论稿、安排评估骑行或给出保守的起始周，不会把猜测包装成正式计划。

## 自测

```bash
python3 scripts/self_test.py
```

自测覆盖自然语言触发、新手引导、无功率计路径、饮食与睡眠问询、案例比较、数据质量识别，以及 Intervals.icu 计划验证与渲染。

## 仓库结构

- `SKILL.md`：技能入口与完整工作流。
- `agents/openai.yaml`：显示信息和默认提示词。
- `references/`：问询、计划、案例比较、证据更新、交接和 Intervals.icu 规则。
- `scripts/icu_plan.py`：计划验证、渲染、预览与部署工具。
- `scripts/self_test.py`：离线回归与可用性测试。

## 隐私与安全

仓库不包含任何运动员数据、账号、邮箱、API Key 或访问令牌。计划部署使用本地环境变量中的凭据，并要求对具体计划进行明确确认。健康异常或伤病风险会触发降级训练或建议专业评估。
